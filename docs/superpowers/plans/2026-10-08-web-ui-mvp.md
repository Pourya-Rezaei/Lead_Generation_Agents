# Web UI MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a local browser-based web panel that lets users manage Campaigns, run Places searches, inspect results, and download JSON/CSV without using the CLI repeatedly.

**Architecture:** Add a thin FastAPI presentation layer under `src/web/` with server-rendered Jinja templates. Routes call the existing `SearchLeadsService`, `LeadStore`, repositories, and export facade; they must not contain direct Apify or SQL logic. The first release binds to localhost, runs searches synchronously, and preserves the existing CLI behavior.

**Tech Stack:** Python 3.10+, FastAPI, Starlette TestClient, Jinja2, existing Pydantic/SQLite/Apify stack, pytest.

## Global Constraints

- Keep the existing CLI commands and behavior unchanged.
- Only source `places` is enabled in the first UI release.
- Bind the development server to `127.0.0.1` by default; do not add public-network access or authentication in this MVP.
- Never expose `APIFY_API_TOKEN`, Authorization headers, raw exception text, or tracebacks in HTML responses or logs.
- Reuse `SearchLeadsService`, `LeadStore`, and existing export behavior instead of duplicating business logic.
- Do not collect private-person data or infer ownership; display only existing public professional business data.
- Add deterministic tests with mocked connectors/Apify; never use a real API token.
- Run `pytest -q` and `git diff --check` before completion.

---

## File Map

- Create `src/web/__init__.py`: web package boundary.
- Create `src/web/app.py`: FastAPI app factory, shared settings/store/service wiring, and safe error boundary.
- Create `src/web/routes.py`: HTTP routes for dashboard, Campaigns, search, and export; no SQL or Apify calls.
- Create `src/web/schemas.py`: small request/form parsing helpers and view models.
- Create `templates/base.html`: shared page shell and navigation.
- Create `templates/dashboard.html`: dashboard summary and recent runs.
- Create `templates/campaigns.html`: Campaign list and creation form.
- Create `templates/campaign_detail.html`: Campaign stats and paginated lead table.
- Create `templates/search.html`: Places search form and validation/error display.
- Create `tests/test_web_app.py`: app construction and dashboard/Campaign/search route tests.
- Create `tests/test_web_export.py`: JSON/CSV response tests.
- Modify `pyproject.toml`: add runtime `fastapi` and `jinja2`; add any required test dependency only if the existing environment does not provide it.
- Modify `README.md`, `docs/01-getting-started.md`, `docs/02-operations-guide.md`, `docs/03-technical-reference.md`, and `docs/09-roadmap.md`: document local UI startup, routes, and completed phase status.
