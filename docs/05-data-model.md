# مدل داده

مدل مرکزی `Lead` نماینده یک کسب‌وکار محلی است.

## فیلدهای اصلی

- `name`: نام کسب‌وکار
- `address`: آدرس قابل نمایش
- `phone`: شماره کاری
- `website`: وب‌سایت
- `category`: عبارت/دسته جست‌وجو
- `rating`: امتیاز منبع
- `reviews`: تعداد reviews
- `source`: منبع رکورد
- `score`: امتیاز کیفیت داخلی

## Normalization

نام، فاصله‌ها، URL و مقادیر خالی پیش از ذخیره normalize می‌شوند. رکوردهای یکسان باید با upsert از تکثیر غیرضروری جلوگیری کنند.

## کیفیت و provenance

نسخه آینده باید برای هر مقدار source URL، زمان جمع‌آوری و raw record ID نگه دارد. داده‌ای که صرفاً از تشابه نام به دست آمده، مالکیت قطعی محسوب نمی‌شود.

## حریم خصوصی

تنها داده عمومی و حرفه‌ای کسب‌وکار مجاز است. اطلاعات خصوصی افراد، حدس مالکیت و داده حساس نباید ذخیره یا enrich شود.
